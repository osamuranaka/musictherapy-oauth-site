Music Therapy YouTube Analytics

YouTubeチャンネル「Music Therapy」の運営者が、自身のチャンネルの視聴実績と収益データを確認し、運営を改善するために使用する分析ツールです。

運営者専用・読み取り専用

アプリでできること

  • YouTube API Servicesを利用し、承認されたチャンネルの動画情報およびYouTube Analyticsの視聴・収益指標を取得します。
  • 取得した指標を、運営者が管理するアクセス制限付きのGoogle Sheetsに蓄積します。
  • 期間比較と運用状況の分析に使用します。分析結果の作成に、運営者が許可した分析支援サービスを使用する場合があります。

このツールは一般向けの公開サービスではありません。第三者のチャンネル情報を収集したり、動画の公開設定・タイトル・説明欄を変更したりする機能はありません。

データの利用と保護

Googleアカウントで許可された読み取り権限のみを利用します。アクセス権の取消、保管データの削除、外部サービスへの共有については、以下のプライバシーポリシーで説明しています。
