利用規約

最終更新日：2026年10月30日

対象と目的

本ツールはYouTubeチャンネル「Music Therapy」の運営者が、自身のチャンネルの実績・推定収益を分析するための専用ツールです。一般の利用者向けの登録・ログイン機能は提供していません。

YouTube利用規約

本ツールはYouTube API Servicesを使用します。本ツールを利用する場合はYouTube利用規約に従うものとします。また、Googleプライバシーポリシーおよび本ツールのプライバシーポリシーをご確認ください。

情報の正確性

YouTube Analyticsの値は後日修正される場合があり、推定収益は確定収益を保証するものではありません。本ツールの自動取得・分析機能は、Google APIや実行環境の変更により停止する場合があります。

アクセス許可と取消

本ツールは運営者本人が明示的に許可した読み取り専用アクセスを使用します。アクセス権はGoogleアカウントの接続管理から取り消すことができます。データ削除についてはプライバシーポリシーをご確認ください。
