プライバシーポリシー

最終更新日：2026年10月30日

本ポリシーは、Music Therapyチャンネル運営者が利用する「Music Therapy YouTube Analytics」（以下「本ツール」）のデータ取扱いを説明するものです。

1. 使用するAPIと取得情報

本ツールはYouTube API Services（YouTube Data API・YouTube Analytics API）を使用します。承認した運営者のYouTubeチャンネルに限り、以下の情報に読み取り専用でアクセスします。

  • チャンネルID、チャンネル名、動画ID、動画タイトル、公開状態などの動画・チャンネル情報
  • 再生回数、視聴時間、視聴維持に関する指標、推定収益などの分析指標
  • 上記情報の取得・更新に必要なOAuth認証トークン

取得するOAuth権限は youtube.readonly および yt-analytics-monetary.readonly です。動画の投稿・削除・公開設定の変更権限は要求しません。

2. 利用目的

自身のチャンネルの実績確認、収益改善、公開コンテンツの企画、履歴照合、データ品質の検証に限り利用します。広告ターゲティングやユーザーデータの販売には利用しません。

3. 保存先・共有・安全対策

  • 分析データは、アクセス制御された運営者管理のGoogle Sheets・Google Driveに保存します。
  • OAuthの認証トークンは運営者管理の非公開領域とGitHub Actions Secretsに保存し、公開用Webサイトのソースコードには配置しません。
  • 同期処理はGitHub Actionsで実行し、Google Cloudの鍵を使わない認証方式を用いてGoogle Sheetsにアクセスします。
  • 運営者の明示的な許可のもと、分析レポート作成のためにChatGPT等の分析支援サービスを利用する場合があります。各サービスへの送信・保存は、それぞれのサービスの設定と規約に従います。

データを不特定多数に公開せず、広告主に販売しません。サービスの運用に必要なGoogle、GitHubおよび運営者が許可した分析サービスを利用する場合があります。

4. 保存期間・削除

分析履歴はチャンネル運営の期間比較や監査に必要な間、保存します。運営者による利用終了・削除依頼・OAuth同意の取消があった場合は、適用されるYouTube API Servicesのポリシーに従い、該当する認証トークンおよび保管済みの認可データを削除します。

削除依頼は下記のお問い合わせフォームから受け付けます。本ツールのデータ削除は運営者が管理するGoogle Sheets・Google Drive・バックアップなどを対象に、必要に応じて手動で実施します。

Googleアカウントのサードパーティとの接続設定からアクセス権を取り消すこともできます。Googleのアクセス権管理ページも利用できます。

5. 当サイトにおけるCookie等

本公開ページは静的サイトとして運用し、運営者独自のアクセス解析タグ、広告タグ、Cookieを設置していません。ホスティング事業者側のログ等については、その提供者のポリシーが適用されます。

6. 参考情報・お問い合わせ

本ツールはYouTube API Servicesを使用します。Googleプライバシーポリシー、YouTube利用規約もご参照ください。

データ取扱いに関する質問、削除・アクセス取消に伴う対応のご依頼は、Music Therapyお問い合わせフォームから受け付けます。
